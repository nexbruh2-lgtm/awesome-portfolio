# Awesome Portfolio 🚀

Modern, responsive, ve güzel tasarlanmış bir portföy ve blog web sitesi.

## ✨ Özellikler

- 📱 **Responsive Tasarım** - Tüm cihazlarda mükemmel görünüm
- 🎨 **Modern Tasarım** - Gradient ve smooth animasyonlar
- 🚀 **Performant** - Hafif ve hızlı yükleme
- 📱 **Mobile Friendly** - Mobil menü ve dokunmatik optimizasyonu
- ⚡ **Smooth Scrolling** - Pürüzsüz sayfa kaydırma
- 🎭 **Animasyonlar** - Giriş ve hover efektleri

## 📋 İçerik Bölümleri

1. **Ana Sayfa (Hero)** - Karşılama ve tanıtım
2. **Portföy** - Proje örnekleri ve teknoloji yığınları
3. **Blog** - Yazı ve makaleler
4. **İletişim** - İletişim formu ve sosyal medya bağlantıları

## 🛠️ Teknolojiler

- HTML5
- CSS3 (Grid, Flexbox, Animasyonlar)
- Vanilla JavaScript
- Font Awesome Icons

## 📁 Proje Yapısı

```
.
├── index.html      # Ana HTML dosyası
├── styles.css      # CSS stileri
├── script.js       # JavaScript işlevselliği
└── README.md       # Bu dosya
```

## 🚀 Başlangıç

1. Repositoryi klonlayın:
```bash
git clone https://github.com/nexbruh2-lgtm/awesome-portfolio.git
```

2. Proje klasörüne gidin:
```bash
cd awesome-portfolio
```

3. `index.html` dosyasını tarayıcıda açın veya bir local server başlatın:
```bash
# Python 3 ile
python -m http.server 8000

# veya Node.js ile
npx http-server
```

4. Tarayıcınızda `http://localhost:8000` adresine gidin

## 🎨 Özelleştirme

### Renkleri Değiştirmek
`styles.css` dosyasındaki `:root` bölümündeki renk değişkenlerini düzenleyin:

```css
:root {
    --primary-color: #667eea;      /* Ana renk */
    --secondary-color: #764ba2;    /* İkincil renk */
    --text-color: #333;             /* Metin rengi */
    --light-bg: #f8f9fa;            /* Açık arka plan */
}
```

### İçeriği Güncellemek
`index.html` dosyasındaki metin, başlıklar ve bağlantıları düzenleyin.

### Sosyal Medya Bağlantıları
`index.html` dosyasındaki social links bölümünde GitHub, Twitter, LinkedIn ve Instagram bağlantılarınızı ekleyin.
